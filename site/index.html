Data structures & algorithms implemented from scratch in Java 21, tested with JUnit 5.

Source on GitHub API docs (Javadoc) Test coverage (JaCoCo) Sorting benchmark

Java can't run directly in the browser, so the demos below are small JavaScript ports of the Java classes (GridAStar, NQueens, Manacher, SlidingWindow). The Java code itself is tested in CI on every push – the reports above are generated by that pipeline.

Click or drag on the grid to draw walls. Both find a shortest path – A* uses the Manhattan distance as a hint and usually looks at far fewer cells.
